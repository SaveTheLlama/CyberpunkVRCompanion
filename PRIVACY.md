# Privacy

Cyberpunk VR Companion is designed as a local Windows utility.

## Local operation

Core profile management, hardware detection, Smart Launch, tuning, Health, Diagnostics, and OpenXR startup logic run on the user's PC.

## Diagnostic packs

The built-in Diagnostic Pack system is designed to sanitize environment-specific identifiers and exclude user-content categories not needed for Companion support, including saves, screenshots, Cyberpunk `UserSettings.json`, crash dumps, Steam IDs, IP addresses, and raw user-directory paths where sanitation rules apply.

Users should still review any archive before posting it publicly.

## Community profiles

Profile export/import is user initiated. Exported packs can include author/channel/hardware/headset/runtime metadata entered by the creator.

## Accounts

The Companion does not require a Cyberpunk VR Companion cloud account for normal operation.
