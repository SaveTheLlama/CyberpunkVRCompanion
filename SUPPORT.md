# Support

Before opening a bug report:

1. Update to the latest Companion release.
2. Run **Health**.
3. If the problem persists, create a **Diagnostic Pack**.
4. Reproduce the issue once if safe to do so.

Include the Companion version, Cyberpunk version, GPU, headset, OpenXR runtime, VR/flatscreen context, reproduction steps, and the sanitized Diagnostic Pack when appropriate.

Do not upload saves, credentials, private screenshots, or other personal files.

For feature usage instructions, see [USER_GUIDE.md](USER_GUIDE.md).
