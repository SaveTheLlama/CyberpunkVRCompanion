# Security Policy

## Reporting a security issue

Please do **not** publish sensitive security details, credentials, private user data, or exploit instructions in a normal public GitHub Issue.

If GitHub Private Vulnerability Reporting is enabled for this repository, use that channel for security-sensitive reports.

For normal crashes, launch failures, profile problems, or compatibility issues, use the standard Bug Report form instead.

## Supported release

Security and reliability fixes are prioritized for the latest stable Cyberpunk VR Companion release.

## Diagnostic data

Review Diagnostic Packs before sharing them. The Companion's diagnostic tooling is designed to sanitize/exclude unnecessary user data, but users remain in control of what they upload publicly.
