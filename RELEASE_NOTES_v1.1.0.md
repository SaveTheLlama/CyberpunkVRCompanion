# Cyberpunk VR Companion v1.1.0

## Public release

v1.1.0 turns the completed Companion into a public-facing one-click onboarding experience.

### Highlights

- Single-file Windows setup EXE workflow.
- Automatic Cyberpunk installation detection.
- Automatic GPU, HMD, and OpenXR detection.
- Automatic local hardware profile creation.
- Automatic **Current Settings (Auto-Detected)** profile capture.
- Locally generated Performance, Balanced, Ray Tracing, and Clarity protected reference profiles.
- Friendly graphics controls independent of prior profile history.
- Automatic Smart Launch readiness repair for clean installs.
- Native x64 launcher and desktop/Start Menu shortcuts.
- True stereo OpenXR startup presentation with flat desktop fallback.
- VR / Flatscreen recovery switcher for scenes or mission steps that may not be completable correctly with the VR port active.
- Health Check and sanitized Diagnostic Pack tools.
- Community profile import/export and compatibility analysis.
- Assisted Tuning that creates new Custom profiles instead of mutating protected originals.
- Upgrade-safe installer and uninstall/full-reset workflows.
